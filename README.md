# kawaii-pomodoro-timer-website

### what is this?: a cute timer to track study time!
### how did i make it?: html, css, and javascript!
### whats in it?: text, timer buttons, images, etc. its a lot. 
---
### how to use: the timer should start automatically, if not, press the pause then resume button and it'll count down. once the timer is over, the screen will show a small popup saying that it's time to take a break!
